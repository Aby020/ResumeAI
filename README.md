# 🚀 ResumeAI

### AI-Powered Resume Analysis & Job Match Platform

A full-stack Django web application that helps job seekers analyze resumes, calculate ATS scores, compare resumes against job descriptions, and manage resumes securely through a modern dashboard.

# 🚀 Installation

```bash
git clone https://github.com/Aby020/ResumeAI.git

cd ResumeAI

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```
